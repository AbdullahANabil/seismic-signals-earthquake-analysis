Seismic Signals: Global Earthquake Analysis

A Python data analysis project examining global earthquake activity using real-world data from the USGS Earthquake API.

Key features

Retrieves live earthquake data using the USGS API
Cleans and transforms JSON data with Pandas
Analyzes earthquake magnitude, depth, location, and frequency
Identifies the strongest earthquakes in the dataset
Examines relationships between earthquake depth and magnitude
Visualizes seismic patterns using Matplotlib

Technologies
Python • Pandas • Requests • Matplotlib • USGS Earthquake API • Jupyter Notebook

Your notebook specifically studies worldwide earthquakes of magnitude 2.5+ from January 1 through March 31, 2026, and includes six research questions covering magnitude distribution, regions, depth correlation, frequency over time, strongest earthquakes, and tectonic boundary regions.
